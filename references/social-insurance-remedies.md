# 社会保险缴费、待遇损失与被迫解除专项

本模块处理用人单位未参保、断缴、少缴、异地或第三方代缴、发放社保补助、要求签署自愿放弃、补缴争议，以及由此产生的医疗、生育、工伤、失业、养老待遇损失和劳动者解除经济补偿问题。

目标不是把所有社保问题都写成一项劳动仲裁请求，而是先确定参保主体、险种、期间和缴费状态，再区分补缴行政路径、待遇经办路径、损失赔偿路径与劳动合同解除路径。

合同、工资、社保和管理主体不一致时先读 [employment-relationship-multiple-entities.md](employment-relationship-multiple-entities.md)；准备仲裁时读 [arbitration-claims-evidence.md](arbitration-claims-evidence.md)；拟发被迫解除通知时同时读 [evidence-claim-matrix.md](evidence-claim-matrix.md)。工伤、职业病和紧急医疗事项同时读 [safety-escalation.md](safety-escalation.md)。

## 一、先制作逐月参保体检表

按险种和月份填写：

| 字段 | 核对内容 |
| --- | --- |
| 劳动关系主体 | 该月真实用人单位及证据 |
| 参保缴费主体 | 系统显示单位、第三方或未参保 |
| 险种 | 养老、医疗、工伤、失业、生育 |
| 缴费状态 | 正常、缺月、中断、补缴、转移中或待核实 |
| 缴费基数 | 申报基数、工资事实和当地上下限 |
| 单位及个人部分 | 已缴、代扣、补助或自行缴纳 |
| 待遇事件 | 就医、生育、事故、失业、退休等发生时间 |
| 当前可补救性 | 可补缴、可更正、待经办核定或已不能补办 |
| 已产生损失 | 项目、金额、凭证及因果关系 |

APP显示“已缴费”只能证明相应记录，不当然证明主体、险种、期间和基数均合法。工资基数、征缴年度和补缴规则具有地区性，提交前从当地人社、医保、税务或经办机构官方渠道核验。

## 二、先分清四条救济路径

### 1. 征缴和补足

社会保险法要求用人单位为职工办理社会保险登记并自行申报、按时足额缴纳。未按时足额缴纳的，由社会保险费征收机构责令限期缴纳或者补足。

单纯要求补办登记、核定基数、补缴险种和期间，通常首先属于社会保险行政、征缴或经办处理。根据当地职能分工确认向人社、医保、税务、社保经办或劳动保障监察中的哪个部门提出，不能把“补缴全部社保”当然作为劳动仲裁可裁决请求。

#### “只能补两年”不是全国统一规则

不得把劳动保障监察违法行为查处的二年期限，直接写成社会保险历史欠费追缴或补缴的实体上限。《劳动保障监察条例》第二十条还区分一次性违法与连续、继续状态；社会保险费征收、行政处罚、劳动保障监察受理和具体补缴经办也不是同一事项。答复时分别核验：

1. 劳动关系及欠费是否处于连续、继续状态；
2. 申请的是监察查处、征收机构追缴、经办补缴、待遇恢复还是损失赔偿；
3. 当地按险种、期间和历史政策设置的补缴条件及材料；
4. 单位是否存续、账册和工资证据是否完整；
5. 是否涉及跨省转移接续。

“超过一定年限需要生效法律文书”也不能泛化为“补缴超过两年均须裁判文书”。全国层面常见的三年规则，是跨省转移接续基本养老保险关系时，对2016年11月28日以后发生的一次性缴纳养老保险费满三年情形的材料审查规则。所需材料可能由法院、审计、劳动保障监察或劳动争议仲裁机构在履行职责时形成；征收机构依法责令补缴形成的文书也可能符合要求，而且原则上由转出地经办机构传递，不应简单要求劳动者事后补办一份判决。三年规则、补缴受理规则和二年监察期限必须分别说明。

- 中国就业网《一次性缴费的养老保险关系转移等问题获明确》：https://chinajob.mohrss.gov.cn/c/2019-10-30/134723.shtml

### 2. 社会保险待遇经办

劳动者已经符合领取或报销条件时，先向相应经办机构申请待遇、补充材料或要求作出书面处理。对经办、征收机构不依法办理登记、核定、支付、转移接续等行为，依法可能进入行政复议或行政诉讼路径。

### 3. 用人单位赔偿待遇损失

劳动者因单位未办理社会保险手续，且经办机构不能补办，导致无法享受社会保险待遇时，可能主张损失赔偿。依次证明：

1. 应由该单位参保及具体期间；
2. 单位没有依法办理或缴费；
3. 劳动者原本符合该项待遇的其他条件；
4. 经办机构不能补办、拒付或实际无法享受；
5. 单位行为与待遇损失之间存在因果关系；
6. 损失项目和金额有当地规则及凭证支持；
7. 劳动者已经采取合理申领和减损措施。

能够通过补缴、更正或申领恢复的，不直接把全部未来待遇折算为确定赔偿。只有APP截图、个人估算或口头咨询时，先取得官方缴费记录和经办意见。

### 4. 劳动者解除及经济补偿

司法解释（二）第十九条规定，用人单位与劳动者约定或劳动者承诺无需缴纳社会保险费的，该约定或承诺无效；用人单位未依法缴纳社会保险费，劳动者依劳动合同法第三十八条第一款第三项解除并请求经济补偿的，人民法院依法支持。

这不意味着看到任何基数差异都应当天发出被迫解除通知。先核对：真实用人单位、未缴事实、险种和期间、是否已依法补正、第三方参保的法律性质、地方经办处理、劳动者真实离职目标、解除通知理由和送达。被迫解除是不可逆行动，事实或请求仍有重大争议时先生成核查、催告，或生成带醒目事实占位符并标明“暂不可直接发送”的律师复核稿。

经核对已有合理事实基础且劳动者明确决定解除时，正式通知不得只要求公司“核对”或“回复”。应站在劳动者立场明确写明：公司未依法缴纳社会保险费的具体险种、期间和表现；该行为违反并触发《劳动合同法》第三十八条第一款第三项；劳动者据此依法解除劳动合同；并依据第四十六条第一项、第四十七条主张经济补偿及其他应结项目。公司是否补正、少缴基数是否等同未依法缴纳、经办结论和地方裁审分歧，应另列为风险，而不是从通知正文中删除劳动者的主张。

## 三、不缴社保协议和社保补助

下列文件不能免除法定义务：

- 双方约定不缴社会保险；
- 劳动者单方承诺自愿放弃；
- 以年轻、已有居民保险、户籍或个人不愿转移为由放弃；
- 公司把单位和个人部分笼统打入工资或发放“社保补助”。

保存协议、工资条、补助项目、公司统一模板和实际缴费记录。不要建议劳动者否认自己曾提出不参保；如实说明提出方和原因，但协议或承诺本身不因此取得免除法定义务的效力。

司法解释（二）同时规定，用人单位依法补缴后，可以请求劳动者返还已支付的社会保险费补偿。因此评估补缴、经济补偿和最终净收益时，必须核对社保补助的名称、金额、期间和是否能够识别，不能把补助和补缴情形当成互不关联的两笔收益。

返还社保补助不等于单位可以要求劳动者承担本应由单位缴纳的法定份额。具体补缴中个人应承担部分、历史补助抵扣和税务处理由经办结果及案件事实决定，不自行编造净额。

## 四、第三方、异地和主体不一致参保

分别核对：劳动合同主体、实际用人单位、工资主体、个税申报主体、参保主体及第三方服务协议。第三方代缴或关联公司参保可能产生：

- 真实用人单位未依法以自身名义履行参保义务；
- 缴费记录存在但特定待遇申领受阻；
- 工作地与参保地不同导致转移、报销或待遇标准问题；
- 实际劳动关系主体和参保记录发生冲突；
- 单位主张集团代缴、派遣或委托代理的抗辩。

第三方记录不当然等于完全未参保，也不当然证明参保合法。先向单位询问三方关系和安排依据，再向当地经办机构核验是否可更正、转移或补缴情形。涉及多个用工主体时制作主体关系图，不向多家公司同时发送相互冲突的解除通知。

## 五、断缴、漏缴情形与缴费基数

### 1. 完全未参保或部分月份中断

按月核对入职、离职、停薪、请假、主体切换和系统记录。不要仅凭到账日期推测缴费所属月份。取得个人权益记录、单位解释和经办口径后，再判断是否补缴、待遇损失或解除。

### 2. 缺少部分险种

分别审查养老、医疗、工伤、失业和生育，不能用“养老已缴”概括全部社会保险义务。某项待遇已经发生时，优先处理申报和救济期限。

### 3. 缴费基数偏低

比较当地基数申报规则、工资组成、上下限、申报年度和实际工资。工资总额、奖金、津贴等是否计入需要按现行统计和地方征缴规则核验。基数差额通常优先走行政核定和补足路径；是否足以支持劳动者解除经济补偿，存在事实程度和地区裁审差异，不作全国统一保证。

#### 先拆分主管环节

不得笼统回答“都由社保局”或“都由税务局”。至少拆成：

| 环节 | 需要确认的机关或机构 |
| --- | --- |
| 劳动关系、未登记或群体性未参保事实 | 当地人社行政部门、劳动保障监察或社保经办机构 |
| 养老、失业、工伤等缴费基数审核或稽核 | 当地社会保险经办机构、人社部门；部分地区由劳动监察先查明 |
| 医疗、生育保险登记、基数或待遇 | 当地医保部门、医保经办机构及税务机关的现行分工 |
| 费款申报、征收、追缴或入库 | 多地由税务机关承担，但是否同时负责争议事实核定须查当地规则 |
| 待遇支付、权益记录和转移接续 | 相应社保或医保经办机构 |

北京现行有效文件明确：已参保但少报、瞒报缴费基数或人数的，由社会保险经办机构通过稽核处理，基数、滞纳金和补缴时限也由其提出处理意见；群体性未参保由劳动保障监察处理。上海现行机制则由税务机关征收社会保险费，人社、医保完成登记并与税务协作，投诉应按职责处理或转送。因此，咨询回复必须给出“首个书面提交部门+要求转送”的方案，不能让劳动者在部门之间只靠口头询问反复奔波。

#### 如何取得法院更易采信的官方认定材料

1. 向有权机构实名书面投诉、举报或申请稽核，逐月列出单位、险种、申报基数、工资事实和差额期间；
2. 同时提交劳动合同、银行工资流水、工资条、个税收入记录、奖金和津贴制度、考勤及单位工资台账线索；不能把银行到账总额未经审查直接等同缴费基数；
3. 取得提交清单、收件回执或受理编号；不属本部门职责时，要求书面告知或依法转送；
4. 明确请求出具书面稽核结果、核定结论、责令改正或补缴文书，至少要求书面答复处理机关、认定期间、基数口径和下一步程序；
5. 单位补缴情形完成后，再取得个人权益记录、缴费明细和入库结果，形成“工资证据—官方核定—实际补缴”的闭环；
6. 对不受理、不履职或基数审核结果有异议的，根据具体行为和当地规则评估行政复议、行政诉讼或监督投诉，不以劳动仲裁代替行政核定。

法院审理待遇损失、解除补偿或其他关联请求时，社保或医保经办机构、征收机关形成的正式文书通常比APP截图、电话录音或个人计算表更能证明基数违法、差额期间和可补救性，但其证明目的仍须结合争议请求逐项说明。

## 六、各类待遇损失的依赖链

### 1. 医疗保险

实际劳动关系与应参保期间 → 就医时缴费和待遇状态 → 医疗费用及报销范围 → 经办机构是否可补缴后追溯报销 → 实际自付差额 → 因果关系。

保存诊断、发票、费用清单、医保结算单、参保记录和经办答复。紧急治疗优先，不为了取证延误就医。

### 2. 生育保险

应参保主体和期间 → 当地连续缴费或补缴情形 → 生育医疗费用和生育津贴资格 → 实际支付主体和金额 → 未获待遇及原因。

怀孕、生育和产假还涉及劳动保护、工资及解除限制，不能只计算一笔生育津贴。地方缴费月数、补缴效果和津贴差额必须实时核验。

### 3. 失业保险

应参保主体和实际缴费 → 缴费年限 → 非因本人意愿中断就业 → 失业登记和求职要求 → 实际申请及经办结果 → 当地标准和可领取期限 → 单位行为造成的差额。

社会保险法第四十五条规定的全国基线包括缴费满一年、非因本人意愿中断就业、已经失业登记并有求职要求。单位还负有及时办理解除终止证明和相关告知义务。劳动者依劳动合同法第三十八条解除是否属于非因本人意愿中断就业，有国家规则支持，但仍应让经办机构根据真实解除材料作出认定。

不能只因单位未缴就直接把当地最高月数乘标准作为损失。还要证明劳动者实际失业、未重新就业、符合其他资格、已申请或存在合理不能申请原因，以及未获待遇与单位行为的因果关系。

### 4. 养老保险

应缴期间和基数 → 是否可以补缴、转移或合并 → 达到待遇年龄时的累计年限 → 经办核定 → 实际养老金差额。距离退休尚远且仍可补缴情形时，不轻率计算终身养老金损失；接近退休、无法补办或跨地区历史复杂时转社保专业人员和律师复核。

### 5. 工伤保险

发生事故伤害或职业病时，先救治、报告并保存现场、劳动关系、医疗和证人材料。单位原则上应在事故伤害发生或职业病诊断鉴定之日起三十日内申请工伤认定；单位未申请的，职工、近亲属或工会通常可在一年内直接申请。具体管辖、期限扣除和材料按事故地、参保地及当地规则立即核验。

单位未依法缴纳工伤保险费而发生工伤的，社会保险法规定相应待遇由用人单位支付，并存在基金先行支付及追偿机制。转包给无用工资格主体等特殊场景，承担工伤保险责任不一定以确认标准劳动关系为唯一前提。

工伤认定、劳动能力鉴定和待遇仲裁是不同程序。不要等劳动关系争议完全结束才关注工伤认定期限，也不要把商业意外险或雇主责任险自动等同于法定工伤保险。

## 七、企业常见抗辩

1. 劳动者主动要求不缴并已经领取补助；
2. 单位已通过第三方或关联公司实际参保，不存在损失；
3. 只是缴费基数争议，应走行政征缴而非劳动仲裁；
4. 已经补缴或可以补缴，待遇损失尚未发生；
5. 劳动者不符合待遇其他条件或未及时申请；
6. 失业是个人辞职或劳动者已经重新就业；
7. 医疗、生育、养老差额来自个人选择或其他原因；
8. 补缴后劳动者应返还已经领取的社保补助；
9. 劳动关系属于其他公司，本单位只是代付或代缴；
10. 事故不是工伤，或者申请已超过期限。

劳动者应围绕主体、缴费、资格、经办结果和因果关系回应，不用一句“社保是强制的”代替完整证明。

## 八、三分钟危机行动卡

### 现在不要做

- 不因发现一个月断缴或基数偏低就立即辞职、停工或发被迫解除通知；
- 不签署倒填日期、虚假自愿放弃或“所有社保待遇已经现金结清”的文件；
- 不把居民保险、商业保险或第三方缴费记录自动当作单位已经依法履行；
- 不使用虚假诊断、失业状态、工资或参保材料申领待遇；
- 工伤和急病时不为取证延误救治或错过申请期限。

### 今天必须保存

- 各险种个人权益记录、缴费主体、期间、基数和查询日期；
- 劳动合同、工资流水、工资条、个税及实际用工主体证据；
- 自愿放弃、社保补助、第三方代缴和公司解释材料；
- 入职离职、主体变更、停保原因和解除证明；
- 医疗、生育、工伤、失业或退休事件的申请、发票、决定和经办回复；
- 已向公司催缴、向行政机关投诉或申请待遇的回执；
- 工伤事故现场、时间、工作任务、证人、诊断和单位报告情况。

### 下一次沟通应询问什么

1. 公司确认的用人单位和参保缴费主体分别是谁；
2. 各险种从何时参保，哪些月份或基数需要补正；
3. 第三方或异地参保的依据及待遇申领安排；
4. 社保补助的项目、金额、期间和补缴后的处理；
5. 公司是否同意办理补缴、更正，预计向哪个机构申报；
6. 已发生待遇事件时，公司准备怎样协助申请并承担差额；
7. 离职原因、停保原因和失业登记信息将如何申报；
8. 工伤事故是否已经报告、由谁在什么期限内申请认定。

### 是否发文

- 状态不明：发参保主体、险种、期间和基数核对函；
- 未缴或断缴：发办理补缴及反馈经办结果催告；
- 第三方代缴：发三方关系和待遇保障确认；
- 待遇事件发生：发协助申报及待遇差额处理通知；
- 离职临近：发停保原因、解除证明和失业手续确认；
- 拟被迫解除：只有事实、法律评价、真实意思和送达均确认后，才生成可发送版本。

## 九、被迫解除决策门

在生成被迫解除通知前逐项回答：

1. 谁是实际用人单位；
2. 哪一险种、哪一期间没有依法缴纳；
3. 证据是官方记录、单位确认还是个人推测；
4. 是否属于合法不参保、转移中、申报周期或可立即纠正；
5. 第三方参保、基数差异和地方裁审口径如何；
6. 劳动者是否已催告及公司是否补正；
7. 劳动者是否真正决定结束劳动关系；
8. 通知中写什么既存事实和法定理由；
9. 向哪个主体、何时、通过什么渠道送达；
10. 如果经济补偿不被支持，劳动者能否承受失去工作的后果。

任一核心项缺失或冲突时，停止生成“可直接发送”的解除通知，改为事实核对、补缴催告或律师复核稿。不得在发送后根据诉讼需要更换解除理由。

## 十、请求成熟度

- **信息不足**：只有APP一页截图，没有险种、期间、基数和主体明细；先做逐月体检表。
- **可行政核查**：缴费异常明确但可补缴情形、主管部门和材料尚未确认；先走官方咨询或投诉处理。
- **待遇申请中**：事件已经发生，优先完成经办申请并取得书面结果。
- **损失请求可准备**：不能补办、待遇资格、实际损失和因果关系已有较强证据。
- **解除请求可评估**：未依法缴纳事实、劳动者真实意思和通知方案已经确定，但仍需检查不可逆风险。
- **立即转专业支持**：工伤职业病、重大医疗生育待遇、临近退休、跨地区历史缴费、企业注销破产或程序期限临近。

## 十一、专项输出顺序

1. 逐月参保体检表和主体关系；
2. 当前属于补缴、经办、损失赔偿还是解除路径；
3. 三分钟危机行动卡；
4. 各险种的事实、资格和证据状态；
5. 可补救性、实际损失和因果关系；
6. 不缴协议、社保补助和返还风险；
7. 第三方代缴、异地参保及企业抗辩；
8. 下一次沟通和行政核验问题；
9. 应发文书、送达及回执；
10. 被迫解除决策门、仲裁请求和专业复核事项。
