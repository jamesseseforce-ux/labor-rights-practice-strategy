# 未休年休假、集中放假与离职折算专项

## 适用范围

用户涉及带薪年休假资格、累计工作年限、入离职折算、春节或停工期间集中放假、跨年度安排、病事假影响、未休年休假工资或离职结算时使用本模块。

先区分年休假与法定节假日、休息日、调休、福利假、事假、病假、婚丧假、产假和工伤停工留薪期。名称相似、工资照发或没有实际工作，均不当然证明某日已经作为年休假安排。

## 一、先建立逐年度台账

不得把多年争议合并成一个总天数。按每个自然年度列出：

| 字段 | 必须核实的内容 |
| --- | --- |
| 劳动关系期间 | 当年入职日、离职日及是否存在主体变更 |
| 连续工作状态 | 入职本单位前是否连续工作满12个月，有无中断及证据 |
| 累计工作年限 | 本单位、其他单位、军龄及依法视同工作期间 |
| 法定基准天数 | 累计1年至不足10年5天；10年至不足20年10天；20年以上15天 |
| 当年折算 | 新入职或离职时分别按法定公式核算，折算不足1整天的部分不计 |
| 不享受情形 | 寒暑假、20天以上带薪事假及不同工龄对应的病假条件 |
| 安排记录 | 通知日期、具体休假日期、申请审批、考勤和工资记录 |
| 假期性质 | 年休假、法定节假日、休息日、调休、福利假或停工 |
| 已付项目 | 正常工资、额外未休年休假工资及结算协议中的对应款项 |
| 时效状态 | 主张时间、单位拒付时间及申请地裁审口径，标成待核验 |

如果公司系统即将关闭、离职账号将被注销，先保存每年度余额、申请审批、休假日历和工资明细的完整页面与导出文件。

## 二、资格与天数

1. 连续工作满12个月是享受年休假的资格条件，但不当然要求在当前单位连续工作满12个月。此前在其他单位连续工作的期间可以用于判断资格。
2. 累计工作年限决定5天、10天或15天档位，可包括在不同单位的工作期间、依法计入的军龄及其他视同工作期间。
3. 证据可以包括档案、社保缴费记录、劳动合同、解除证明、工资记录、军龄材料及其他具有证明力的文件。社保记录有中断或主体异常时，不可仅凭一项记录作结论。
4. 新进入单位且已具备资格的，当年度天数按“当年度在本单位剩余日历天数÷365×全年应休天数”折算，不足1整天的部分不计。
5. 劳动关系解除或终止时，当年度未休天数按“当年度已过日历天数÷365×全年应休天数－当年度已安排天数”折算，不足1整天的部分不支付。单位已经安排超过折算天数的，一般不应倒扣。
6. 劳动合同、集体合同或规章制度约定的天数、工资标准高于法定标准时，保留并核验该更高标准；不要擅自把法定最低标准当成唯一标准。

计算结果必须同时显示公式、参数来源、取整规则和待核证据，避免只给一个无法复算的总数。

## 三、不享受当年度年休假的条件

逐项核对，不因用户“休过很久”就直接认定：

- 依法享受寒暑假且休假天数多于年休假天数；
- 请事假累计20天以上且单位按规定不扣工资；
- 累计工作满1年不满10年，请病假累计2个月以上；
- 累计工作满10年不满20年，请病假累计3个月以上；
- 累计工作满20年以上，请病假累计4个月以上。

探亲假、婚丧假、产假和因工伤停工留薪期间不当然冲抵年休假。病事假天数、是否扣薪、累计工作档位和跨年度时间必须分别核证。

## 四、单位安排义务与劳动者意思表示

单位应结合生产经营情况并考虑劳动者本人意愿统筹安排，可以集中安排，也可以分段安排。一般应在本年度安排；确因工作特点需要跨年度安排的，可以跨1个年度安排。

劳动者没有主动提交申请，不等于当然放弃年休假。遇到“你没申请所以没有补偿”的抗辩，应追问单位何时、以何种方式提供了可休日期，劳动者是否真正收到并能实际休假。

只有单位已安排年休假，而劳动者因本人原因书面提出不休时，才重点审查是否仅支付正常工作期间工资。必须核验该书面材料是否真实、自愿、针对明确日期形成；不得把笼统的入职承诺、统一模板或事后补签自动视为有效放弃。

## 五、春节连休、停工与集中放假

集中安排本身并非当然违法，但必须逐日拆分：

1. 国家法定休假日、休息日不计入年休假天数；
2. 单位额外给予的福利假是否可以与年休假并行或冲抵，要看真实通知、制度和履行，不可只看“放假”名称；
3. 停工、待岗、居家待命、调休和年休假的法律性质不同，应核验员工是否被要求保持在线、处理工作、接受召回或实际工作；
4. 单位应能说明安排决定、具体日期、提前通知、考勤标注和工资支付。争议发生后追溯性把既往停工全部标成年休假，不应不经审查即予认可；
5. 劳动者在公司声称的年休假日期实际工作的，保存邮件、系统日志、会议、工单、客户沟通和主管指令，但不得越权取得商业秘密或个人信息。

不要机械主张“未经本人同意的统一放假一律无效”。应分别审查单位安排权、是否考虑本人意愿、具体日期能否识别、法定节假日和休息日是否排除，以及劳动者是否确实获得休息。

## 六、未休年休假工资

单位因工作需要不能安排且经劳动者同意不安排时，应按规定支付未休年休假工资。法定“300%”包含单位已经支付的正常工作期间工资；若正常工资已经支付，通常核算的是额外200%的差额，不得再次重复计算正常工资部分。

日工资通常按月工资除以21.75折算。月工资基数原则上取支付未休年休假工资前12个月剔除加班工资后的月平均工资；不足12个月的，按实际月份计算。计件、提成或其他绩效工资人员也应依规定核算，不能因结构复杂直接按基本工资替代。

计算底稿至少列：年度、法定或更高标准天数、折算天数、已休天数、争议天数、月工资基数、日工资、已支付正常工资、额外比例及暂计金额。

## 七、证据与企业抗辩

劳动者优先保存：

- 历年劳动合同、社保缴费记录、档案或前单位解除证明；
- 休假制度的适用版本及公示、培训或签收记录；
- OA或考勤系统的年度余额、申请、驳回、撤回和审批记录；
- 春节、停工、闭店和集中放假通知及其发送时间；
- 被称为休假日期内的工作指令、成果和系统使用记录；
- 工资条、银行流水、离职结算表和清结协议；
- 与HR、主管关于休假性质、余额和结算的原始沟通。

预判并逐项回应单位可能提出的抗辩：未连续工作满12个月、累计工龄档位不足、病事假达到排除条件、已经实际安排、劳动者书面拒绝休假、春节或停工已集中冲抵、优于法定标准的企业假已用完、离职协议已清结，以及仲裁时效届满。

不要因休假台账由单位掌握就停止取证。劳动者仍需完成连续工作、累计工龄、劳动关系期间、主张经过和未休事实的初步证据闭环，并指出哪些原始记录由单位控制。

## 八、时效与程序

未休年休假工资的请求性质、仲裁时效起算和可支持年度在不同地区、不同裁审观点下可能存在差异。不得承诺“全部历史年度均可追回”，也不得未经核验就把所有年度一并排除。

建立逐年度时效表：该年度安排期限、是否依法跨年度、劳动关系是否终止、单位何时明确拒付、劳动者何时主张、何时申请仲裁。提交前核验申请地最新仲裁和法院口径；临近任何可能期限时先保留申请权，再完善非关键材料。

## 九、三分钟危机行动卡

### 今天必须保存什么

- 休假系统首页和每年度明细，截取页面标题、账号、日期、余额、申请状态和完整上下文；
- 公司休假制度、集中放假通知、春节日历、考勤和工资明细；
- 入职前后连续工作及累计工龄材料；
- 公司称为年休假期间的实际工作证据；
- 即将要求签署的离职结算、休假确认或权利放弃文本，先留副本再决定是否签署。

### 下一次沟通应询问什么

- 请公司逐年度确认应休、已休、未休天数及每一天的具体日期；
- 请说明集中放假中哪些是法定节假日、休息日、调休、福利假和年休假；
- 请提供适用制度版本、安排通知、审批记录和计算依据；
- 离职时请说明折算公式、工资基数、已付正常工资和额外差额；
- 如果公司称劳动者放弃，请明确放弃的日期、本人书面申请和单位此前的具体安排。

### 是否需要发出书面文书并存证

当余额即将清零、系统将关闭、单位口头称已冲抵、离职结算未列明或公司要求签署放弃时，通常需要发出书面确认。文书应客观列出已知数据和待确认事项，不先写死全部天数或金额；通过企业邮箱、OA、可核验的即时通信或可证明送达的方式发送并保留原始载体。

## 十、停止规则

出现以下情况，不直接给“可提交定稿”，先提示当地律师或专业人员复核：

- 跨多年且时效将决定大部分请求；
- 病假、产假、工伤停工留薪期或长期医疗期与年休假交叉；
- 事业单位、特殊身份或地方另有专门规则；
- 已签署广泛清结、放弃或和解文件；
- 证据只能通过越权访问公司系统或获取第三方隐私取得；
- 未休年休假与违法解除、工资结构、关联主体或高额奖金等争议高度交织。

## 十一、输出顺序

1. 紧急时先给三分钟危机行动卡；
2. 输出逐年度年休假台账和仍缺字段；
3. 区分资格、法定档位、新入职折算、离职折算和排除条件；
4. 逐日判断集中放假或停工的性质；
5. 列企业抗辩、双方证据和待核地方口径；
6. 给出未休年休假工资计算底稿，不重复计算正常工资；
7. 说明沟通路径、行政咨询或仲裁准备及期限风险；
8. 需要时按 [document-contracts.md](document-contracts.md) 生成对应文书，并写明发送和存证方式。
