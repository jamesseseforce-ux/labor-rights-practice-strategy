# 劳动关系确认、未签合同与关联主体用工专项

本模块处理没有书面合同、合同与实际用工主体不一致、工资和社保由不同单位承担、关联公司交替签约、劳务派遣或业务外包、合作承揽、注册个体工商户、新业态平台用工，以及未签书面合同二倍工资和无固定期限合同衔接问题。

目标不是找到一家“看起来最像公司”的主体就申请仲裁，而是还原每一期间由谁招用、管理、支付、提供生产条件并决定进退，再确定劳动关系主体、责任主体和请求范围。

进入仲裁时同时读 [arbitration-claims-evidence.md](arbitration-claims-evidence.md)；涉及工资支付读 [wage-bonus-commission.md](wage-bonus-commission.md)；涉及解除读 [unlawful-termination-remedies.md](unlawful-termination-remedies.md)。

## 一、先建立主体关系图

对每一个可能相关的单位分别填写：

| 事实维度 | 需要核对的内容 |
| --- | --- |
| 招聘录用 | 谁发布岗位、面试、发录用通知、决定入职 |
| 合同文件 | 与谁签劳动合同、劳务、合作、承揽或派遣文件 |
| 日常管理 | 谁安排任务、排班考勤、审批请假、考核奖惩 |
| 报酬决定 | 谁确定工资、奖金提成规则和调整方案 |
| 实际支付 | 谁转账、申报个税、报销及提供工资条 |
| 社会保险 | 谁参保、缴费期间和基数，是否第三方代缴 |
| 生产条件 | 工作场所、账号、设备、客户和系统由谁提供 |
| 组织归属 | 工牌、邮箱、通讯录、汇报线、对外名义和业务归属 |
| 人事决定 | 谁调岗、停权、要求交接、辞退或出具离职证明 |
| 主体关系 | 股东、法定代表人、地址、品牌、业务及人员是否关联 |

按月份或主体变化节点填写，不能用当前状态覆盖历史期间。主体图用于识别证据和请求，不等于所有出现过的单位都共同建立劳动关系。

## 二、劳动关系的实质判断

### 1. 先看主体资格和真实用工

核对劳动者和单位是否具备建立劳动关系的主体资格，再审查实际履行。劳动合同法以实际用工时间作为建立劳动关系的重要起点；没有合同、合同写成合作或报酬叫“服务费”，均不单独决定关系性质。

### 2. 劳动管理和从属性

综合审查：

- 劳动者能否自主决定工作时间、工作量、地点和是否接单；
- 工作过程是否受到指令、监督、考勤、算法、纪律和奖惩控制；
- 报酬标准、交易价格及客户资源由谁决定；
- 工作是否持续稳定，收入是否具有工资性和依赖性；
- 劳动者是否被纳入单位组织体系，以单位名义对外工作；
- 劳动内容是否属于单位业务组成部分；
- 劳动者能否自行组织他人替代履行并承担经营风险；
- 设备、数据、场所和主要生产资料由谁控制。

不是机械数指标。固定坐班、月薪和考勤通常具有较强指向性，但弹性时间、计件报酬或远程工作并不当然排除劳动关系；能够自由接单、定价、拒单、同时自主经营并承担盈亏，则可能削弱劳动管理和从属性。

### 3. 文件名称与实际履行冲突

合作协议、承揽协议、主播协议、车辆管理协议、个体工商户或灵活用工平台结算，只是证据之一。逐条比较文件约定与真实履行：谁实际管理、规则是否真正执行、劳动者有没有独立经营能力和交易自主权。

不得为了主张劳动关系隐瞒劳动者自主经营、同时服务多个客户、自定价格、雇佣助手或承担成本风险等不利事实。

## 三、确认劳动关系的期间

请求不仅要回答“有没有”，还要明确从哪一天到哪一天。核对：

- 首次实际提供劳动而非仅收到录用通知的日期；
- 培训、试工、试岗是否已经受单位管理并实际提供劳动；
- 合同主体、工作地点、工资和管理主体变化节点；
- 停工、待岗、长期请假或中断服务期间；
- 最后提供劳动、解除、终止或转由其他主体用工的日期；
- 前后期间是否连续，是否存在真实终止和重新招用。

只有零散转账或一次工作任务时，不直接写成长期连续劳动关系。存在多个主体时，分别建立期间轴，避免对同一期间无依据地要求与多家公司同时存在完整劳动关系。

## 四、关联公司分工或交替用工

### 1. 不把“关联”自动等同于共同用工

股东、法定代表人、办公地址、品牌或财务相同，只能说明关联线索。仍需证明每家公司在招用、管理、支付和人事决定中的实际行为，以及劳动者是否能够区分其服务对象。

### 2. 分工用工

常见状态是A公司签合同，B公司发工资，C公司管理或缴社保。依次判断：

- 是否为真实合法的委托支付、集团人事共享或代缴；
- 劳动者实际接受谁的劳动管理；
- 各主体对外如何向劳动者表达关系；
- 哪个主体决定工资、岗位和解除；
- 是否存在刻意分散法定义务、主体空壳或责任逃避。

不能只抓住单一工资流水认定B为用人单位，也不能因A有劳动合同就忽略合同是否真实履行。

### 3. 交替签约和工龄承继

按每次主体变更检查：劳动者是否离岗、结算补偿、重新招聘、岗位和管理是否变化、变更由谁安排、是否属于非因劳动者本人原因。劳动者仍在原场所岗位连续工作，关联单位轮流订立合同，可能影响经济补偿或赔偿金的工作年限合并计算。

工龄能够合并计算，不当然意味着前后所有主体对全部债务承担连带责任。分别确定劳动关系期间、具体债务发生主体和责任依据。

## 五、派遣、外包与名义用工

### 1. 劳务派遣

核对派遣单位是否具备许可、谁签合同和缴纳社保、派遣协议、用工单位岗位及日常管理。派遣单位通常是用人单位，用工单位承担法律规定的用工义务；给被派遣劳动者造成损害时是否承担连带责任，须结合具体违法行为和劳动合同法第九十二条审查。

违法派遣、长期在用工单位工作或接受其管理，不当然使劳动关系自动转移给用工单位。不得用“实际工作地点”单一因素替代派遣法律结构。

### 2. 业务外包

区分承包方真正组织、管理并对工作成果负责，还是仅提供合同、发薪或开票，发包方仍直接招用和支配劳动者。审查：

- 谁决定人员数量、班次、请假、考核和去留；
- 承包方是否有独立管理人员、业务组织和经营风险；
- 结算按成果、项目还是按人头和工时；
- 劳动者向谁汇报，遵守谁的制度；
- 外包合同是否实际履行。

名为外包但承包方未实际管理，不能成为隔断真实劳动管理的当然依据。反之，发包方对服务质量的验收和现场安全要求，也不必然等于对个人实施劳动管理。

### 3. 无照承包、挂靠和个人招用

发包人、承包人、挂靠方和实际招用人可能适用不同的用工主体责任或共同责任规则，不一定形成标准劳动关系。先核验经营资格、工程或业务层级、招用行为和请求类型，避免把“承担用工主体责任”与“确认劳动关系”混写。

## 六、未签书面劳动合同二倍工资

### 1. 先区分四种状态

1. 从未签署任何书面劳动合同；
2. 实际已经签署，但劳动者未取得本人文本；
3. 签署了电子劳动合同，需要核验身份、签署和可调取性；
4. 签有劳务、合作或承揽文件，其内容是否已经具备劳动合同的主要事项需审查。

“手里没有合同”不等于“双方从未订立”。要求公司提供合同文本、签署记录和完整版本，并保存入职时的文件流转、电子签约短信、系统记录和经办人沟通。

### 2. 请求依赖链

劳动关系及用工主体 → 实际用工起点 → 是否订立书面劳动合同 → 未签原因及例外 → 可请求月份 → 每月工资基数 → 已支付部分 → 仲裁时效。

任何一环不清楚，都不能直接用入职月工资乘以全部工作月数。

### 3. 期间和计算

劳动合同法第十条要求建立劳动关系时订立书面劳动合同；已用工未同时订立的，应在法定期间内订立。超过一个月不满一年未订立时，按第八十二条审查二倍工资责任。司法解释（二）明确二倍工资按月计算，不满一个月按该月实际工作日计算。

计算底稿逐月记录：该月实际工作日、应发工资口径、已经正常支付的一倍工资、二倍工资差额、合同签署或补签状态及时效。不得按整个劳动关系存续期机械计算。

### 4. 不支付二倍工资和特殊衔接

司法解释（二）规定，用人单位证明因不可抗力、劳动者本人故意或重大过失等法定情形未订立的，可以排除二倍工资责任。必须要求单位证明具体事实，不能把劳动者未主动催签、普通疏忽或管理人员身份自动等同于故意、重大过失。

合同期满因法定保护、服务期或工会任期依法自动续延的，不属于未订立书面合同。用工满一年后依法视为已订立无固定期限劳动合同的，劳动者可依法请求订立书面合同，但不能仅以单位未及时补订书面文本继续主张视为无固定期限期间的二倍工资。

二倍工资的仲裁时效和工资基数存在地区裁审差异，提交前核验申请地现行口径，不用其他省市案例直接替代。

## 七、无固定期限劳动合同衔接

核对连续工作年限、历次合同次数和期限、延长或自动续延、劳动者是否提出固定期限选择、主体是否由关联单位安排更换以及当前是否仍在履行。

司法解释（二）对“连续订立二次固定期限劳动合同”的部分情形作了细化。达到条件后的请求可能包括订立无固定期限合同、确认关系状态或其他责任，但不能只因看到两份合同就跳过合同顺序、真实意思、法定例外和后续履行。

### 二次固定期限合同期满不续签：N还是2N

不能只数合同份数。按以下条件树回答：

1. **尚未进入强制订立无固定期限合同条件**：普通固定期限合同期满，单位不续签，通常依劳动合同法第四十四条、第四十六条处理经济补偿N；单位维持或提高条件续订而劳动者拒绝的，另行审查是否支付经济补偿。
2. **已经连续订立二次固定期限合同**：先排除劳动合同法第三十九条以及第四十条第一项、第二项情形，再核对劳动者是否在期满前表达继续工作的意愿、请求或同意续订，以及是否主动要求固定期限合同。
3. **条件成立且劳动者要求或同意续订**：除劳动者提出订立固定期限外，单位原则上负有订立无固定期限劳动合同的义务。单位仅发“不续签”通知并终止，可能构成违法终止；劳动者可依第四十八条选择继续履行，或者在不能继续履行或不要求继续履行时主张第八十七条赔偿金2N。
4. **单位没有终止而继续用工**：重点评估订立无固定期限劳动合同及未依法签订书面无固定期限合同的二倍工资责任，不能把它与违法终止2N混成同一项目。
5. **证据或地方口径有冲突**：上海等地历史裁判曾对单位是否享有第二次合同期满终止权存在分歧；最高人民法院法答网答问和2025年司法解释（二）所体现的最新全国方向，更重视劳动者依法取得的无固定期限合同选择权。具体案件仍应核验申请地最新裁审口径。

最关键的存证不是等收到不续签通知后再回忆，而是在第二份合同期满前书面表态：“本人愿意继续履行劳动合同，并依法请求订立无固定期限劳动合同”。保存两份及全部续延合同、公司通知、劳动者回复、送达记录、继续到岗和单位拒绝提供工作的证据。不能教劳动者倒签、补造期满前申请。

## 八、企业常见抗辩及回应

1. 双方已明确签署合作或承揽协议，不是劳动关系；
2. 劳动者工作自由、按单结算且可以拒绝任务；
3. 劳动者注册个体工商户并自行开票；
4. 工资转账只是代付，社保缴纳只是委托代理；
5. 实际管理来自项目验收或安全要求，不是劳动管理；
6. 劳动者是股东、高管、法定代表人或承包负责人；
7. 已经签过纸质或电子劳动合同，只是劳动者称未拿到；
8. 未签合同由劳动者本人故意或重大过失造成；
9. 前后公司用工已经真实结算、离职并重新招用；
10. 派遣或外包文件真实有效，劳动关系属于另一主体。

回应必须落到实际履行和证据，不以“公司在规避责任”这一结论代替管理、支付、组织和人事决定事实。

## 九、三分钟危机行动卡

### 现在不要做

- 不按公司要求补签虚假入职日、倒签日期或空白合同；
- 不为证明劳动关系带走无关客户资料、源代码或他人个人信息；
- 不因工资由第三方支付就自行认定已经换了用人单位；
- 不在主体未查清时向所有关联公司发送相互矛盾的辞职或解除通知；
- 不隐藏真实合作经营、自主接单或已签电子合同的事实。

### 今天必须保存

- 招聘广告、面试、录用通知、入职登记和培训安排；
- 工牌、邮箱、通讯录、组织架构、汇报线和工作账号；
- 考勤、排班、请假、任务、审批、考核、奖惩和解除记录；
- 工资条、银行流水、个税、社保、报销和各支付主体；
- 劳动、劳务、合作、承揽、派遣及电子签约的所有版本；
- 主体变更、工龄承继、合同换签和补偿结算沟通；
- 各公司登记信息、办公地址、品牌和授权人员线索；
- 能够说明实际工作期间、工作成果和接受管理的合法材料。

### 下一次沟通应询问什么

1. 公司确认的用人单位全称和入职日期是什么；
2. 工资、社保和日常管理为何由不同主体承担；
3. 是否已经签署劳动合同，签署日期、方式和可取得文本在哪里；
4. 如果要求换签，原关系如何解除、工龄和债务如何承继；
5. 外包或派遣结构中谁负责招聘、考勤、请假、工资和解除；
6. 下一工作日劳动者向谁报到并接受谁的工作安排；
7. 公司是否认可此前连续工作期间以及未结款项归属。

### 是否发文

- 主体不清：发用工主体、工资社保及管理关系确认；
- 未取得合同：发劳动合同签署状态及文本提供请求；
- 要求换签：发主体变更、工龄和债务承继确认；
- 外包派遣口径冲突：发实际用工安排及责任主体确认；
- 仲裁准备：形成主体关系图、劳动关系期间表和证据目录。

文书只能确认真实过程，不能通过向多家公司同时表述“你公司是我唯一用人单位”制造相互冲突的证据。

## 十、请求成熟度

- **未成熟**：只有一项转账、工作群或名片，主体和管理事实无法闭合；先补关系图和期间证据。
- **可进一步确认**：存在稳定工作和管理线索，但签约、支付、社保主体冲突；先发确认文书并取得登记信息。
- **可准备仲裁**：用工期间、主要管理主体、合同状态及下游请求已经能够具体表达。
- **需专项复核**：多个主体同期间交叉管理、派遣外包违法、主体注销、平台算法、境外用工或无照承包责任复杂。

## 十一、专项输出顺序

1. 主体关系图和逐期间用工结构；
2. 劳动关系成立与否的有利、不利事实；
3. 可能的用人单位、责任主体及尚不能确定部分；
4. 三分钟危机行动卡；
5. 劳动关系期间和主体变化时间线；
6. 未签合同、二倍工资和无固定期限合同分析；
7. 关联、派遣、外包或合作抗辩及回应；
8. 证据状态、质量和补强任务；
9. 应发文书及送达留痕；
10. 仲裁请求成熟度、管辖和律师复核事项。
