# 劳动维权实务方略

面向中国内地劳动者的 AI Skill：梳理事实、保存证据、设计沟通、准备维权文书和仲裁材料。

版本：1.0.0。技术名称：`labor-rights-practice-strategy`。

这是供支持 `SKILL.md` 的 AI Agent 加载的技能文件包，不是独立运行的软件，也不是律师代理服务。

## 能帮你做什么

覆盖入职试用、PIP、调岗降薪、工资奖金、协商解除、单位辞退、社保、年休假、竞业和劳动仲裁准备。紧急时先回答四件事：

- 现在不要做什么；
- 今天必须保存什么、怎么保存；
- 下一次沟通问什么、如何留证；
- 是否需要发文、发什么文书。

坚持劳动者侧合法权益保护：在真实事实和证据基础上形成有力度的主张，不制造事实，不承诺胜诉。

## 下载与使用

1. 从本仓库的 Releases 下载 `labor-rights-practice-strategy-v1.0.0.zip`，而非只下载 `SKILL.md`。
2. 解压后得到 `labor-rights-practice-strategy` 文件夹，内含 `SKILL.md`、`VERSION`、`agents`、`references` 和本说明。
3. 按所用 AI Agent 的官方安装说明添加整个文件夹，保留目录结构。若已有旧版，先备份，再按平台更新流程替换，避免新旧文件混用。
4. 新建任务，可直接描述事实；支持显式技能调用的平台也可输入：`使用 $labor-rights-practice-strategy 分析我的劳动争议。`

Skill自身不需要安装PyYAML、OCR或其他Python依赖。联网核验、读取附件和生成下载文件取决于承载平台的能力与权限；不能读取附件时，请改传脱敏文字，不要把上传成功当作已经识别。

## 一个完整使用示例

以下为合成演示，不是真实案件或固定答案。

**先问：**

> 公司停了我的门禁，让我回家等通知，但我没有辞职。今晚和明天该做什么？只给紧急行动卡。

**首轮应得到：**保存公司原话、停权记录和履职证据的具体方法；确认工作安排的沟通问题；对到岗及被拒进入的分情况建议；可使用的《解除状态及继续履职确认函》名称、用途和风险，并询问是否需要范文。

**再说：**

> 需要，请给完整范文。公司叫某科技公司，我叫李某，工作地杭州；缺失信息用方括号标注。

**下一轮应得到：**完整可复制文书、待核对字段、发送与存证方法、风险提示和免责声明。事实不足的稿件不能冒充可直接发送的定稿。

直接要求文书时不必等两轮，例如：“请起草《PIP收到确认、异议及资源申请》，缺失信息用方括号标注。”

## 输错或生成失败怎么办

- 信息输错：`更正：[原信息]应为[正确信息]，只更新受影响部分。`
- 文书中断：`请从标题开始重发完整《文书名称》，不要只续写后半段。`
- 回答偏题：`我的目标是继续履职，不是辞职，请按这个目标重做。`
- 文件读不出：改贴脱敏文字，注明需要审查的条款；要求明确哪些内容实际读取成功。
- 地方网页不可用：先取得证据准备方案，并要求列出待官方核实的机构和事项，不能用猜测代替核验。

## 风险与隐私

**辞职、被迫解除、竞业解除、权利放弃及终局清结可能产生难以逆转的后果。相关文书原则上暂不直接发送，先携完整材料当面咨询当地劳动法律师。**

回复不替代律师审查，不建立委托代理关系。全国及地方规则、时效、金额参数、主管部门和提交渠道须按咨询时点核验。

运行数据处理和费用取决于所用AI平台。本项目不保证完全离线、零成本或文件绝不传出本机。请先遮蔽身份证号、住址、账户、客户资料和商业秘密，不要提交未经授权披露的材料；不要绕过权限取证。

如在仓库反馈问题，只描述合成或充分脱敏的情形，不公开真实案件全文、身份信息或账号凭据。
